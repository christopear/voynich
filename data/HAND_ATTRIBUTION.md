# Scribe (hand) attribution used from stage 31

No new file. Stage 31 reads the `$H` page variable already present in
`data/ZL3b-n.txt` (ZL transliteration, version 3b, 13 May 2025).

Provenance, checked 9 October 2026: René Zandbergen's transliteration notes
(<https://www.voynich.nu/transcr.html>, note 25, which belongs to the ZL file
entry) say that the ZL versions use IVTFF format "including paragraph start
markers and LFD hands in variable $H". LFD is Lisa Fagin Davis's five-scribe
palaeographic attribution. `$C` holds Currier's hand. In this file `$H` takes
the values 1–5 on 226 pages (one page `@`). `$C` is partial (1–5, X, Y).

These are scholarly attributions, not ground truth. Stage 31 applies them by
page identifier, including to IT2a panels, whose pages use ZL identifiers.
Inline `<@...>` changes are not used for hands.
