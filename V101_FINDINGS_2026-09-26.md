# v101 stage: findings

26 September 2026. Protocol: `V101_PROTOCOL.md` (commit `090e986`, written after
the mapping and before any variant or port statistic). Results are in
`results/v101_2026-09-26/`.

## Summary

* **Parser and mapping.** Glen Claston's v101 file parses completely: 4,486
  records, of which 3,978 are text lines. A v101 → EVA mapping inferred by EM
  alignment, with no hand-made table, matches ZL3b on **89.7%** of 32,812
  aligned words (character error 3.9%). That is the same agreement as IT2a vs
  ZL3b on identical loci (90.1%, character error 3.4%). v101 is therefore an
  ordinary third transcription at the EVA level, plus extra glyph distinctions.
* **Glyph variants (Part A).** Eight EVA classes have testable v101 variant
  sets. **None is letter-like.** In every set where the residual test is
  calibrated (d, k, p, r, sh, y), adding the word's identity does not improve
  prediction of the variant beyond position, scribe, location and neighbouring
  glyphs. In five of the six it makes prediction slightly worse, and for k it
  makes no difference. In calibration the same
  test detected a synthetic letter-like split in 85–100% of replicates at these
  sample sizes, with no false alarms.
* **What the variants look like instead (descriptive).** The attribution gate
  failed, so these labels are not interpretable under the pre-set rules. Most
  variant choice is **unexplained by any feature** (explained share 1–7% for
  d, k, r, y, sh). The exceptions are the gallows pairs p (`g`/`j`) and f
  (`f`/`u`), where one form strongly prefers word-initial position, and d
  (`8`/`7`), which varies with hand and the preceding glyph.
* **Ports (Part B).** The Currier B ending-coupling result **replicates on
  v101**, a third transcription, in both crossed designs. The gain is larger
  than on ZL3b: +0.065 bits collapsed, against +0.028 on ZL3b. The
  hidden-boundary result also **replicates** (stem + next initial 61.3% vs
  stem-only 54.4%, McNemar p = 0.0004). §19, as on ZL3b, does not pass its
  interpretation rule.
* **Do the variants help any ported analysis?** By the pre-set rule
  (FULL must beat both COLLAPSED and SHAM), **no**. For the 06 design the rule
  returns "variants are noise": FULL's coupling gain is 0.010–0.013 bits
  *smaller*. Descriptively, though, the variant spelling of the stem does
  predict the ending better than collapsed or shuffled variants (0.009–0.022
  bits). So the variants carry a little *within-word* information about the
  ending, and none about the next word.

## Step 1. Parser and inferred mapping

`code/v101.py`, `code/19_v101_mapping.py`, and `mapping.json`,
`agreement.json`, `line_alignment.csv`.

* **Format.** The file is latin-1 with CRLF endings. `.` is a space, `,` an
  uncertain space, `-` a line end and `=` a paragraph end (labels also end in
  `=`). `*` and `?` make a word unclean. Page ids map to ZL3b directly, except
  `rose` → `fRos` and `101r1-r2`/`101v2-v1` → `f101r`/`f101v`. Language, hand,
  section and quire come from the ZL3b page header, and from the aligned ZL3b
  line where inline changes exist (f115r).
* **Mapping.** A monotone EM aligner lets each v101 symbol emit 0–4 EVA
  characters. It was seeded with 15,657 word pairs (same page and line number,
  same word count). Two rounds of page-level line alignment and word alignment
  followed, and the final EM ran on 32,667 word pairs with normalised edit
  distance ≤ 0.5. All 3,978 v101 text lines align to a ZL3b line, 3,976 of them
  to paragraph lines.
* **Recovered symbols, among others:** `o`→o, `9`→y, `a`→a, `c`→e, `1`→ch,
  `e`→l, `8`/`7`→d, `h`→k, `y`→r, `k`→t, `4`→q, `m`→iin, `n`→in, `M`→iiin,
  `z`→ir, `2`→sh, `C`→ee, `d`→eee, `K`→cth, `H`→ckh, `J`/`G`→cph, `g`/`j`→p,
  `f`/`u`→f, `p`→m. Alignment purity is ≥ 0.95 for almost every frequent
  symbol.
* **One genuinely ambiguous symbol.** `A` (666 occurrences) aligns to EVA o 59%
  and a 30% of the time. EVA readers split it, so it was treated as ambiguous,
  not as a variant.

## Part A. Glyph-variant test

`code/20_v101_variant_test.py`, `variant_calibration.json`,
`variant_test.json`. Runtime about 10 minutes on 4 cores.

### Calibration (synthetic variants on o, a, e, ch, l; 20 replicates per cell)

| | n = 300 | n = 1000 | n = 5000 |
|---|---:|---:|---:|
| Letter-like flagged: NULL / POS / SCRIBE / NB | 0 / 0 / 5 / 0% | 0 / 0 / 0 / 0% | 0 / 0 / 0 / 0% |
| Letter-like flagged: WIDE (safeguard) | 0% | 0% | 0% |
| **Letter-like flagged: LETTER (power)** | 25% | **85%** | **100%** |
| Correct attribution: POS / SCRIBE / NB | 20 / 10 / 45% | 85 / **15** / 80% | 100 / **70** / 100% |
| NULL → "unexplained" | 100% | 95% | 100% |
| Residual verdicts interpretable (G1, G2, G4) | no | **yes** | **yes** |
| Attribution interpretable (G3, G5) | no | no | no |

* **The residual test is valid and powerful** from n = 1000. It had no false
  letter-like calls in any regime, and the WIDE safeguard held. It detected a
  word-level split (mean residual gain 0.06 bits at n = 1000, 0.10 at 5000) in
  85–100% of replicates.
* **Attribution fails G3 at every size**, because of the SCRIBE control. The
  failures are almost all misses ("unexplained") rather than wrong labels: a
  0.3-vs-0.1 hand effect is too weak for the unique-gain rule, partly because
  hand is collinear with quire and section. By the pre-set rule, positional,
  scribal and contextual labels on Voynich are descriptive only.

**Pre-set verdicts.** For d, y, k, r, sh and p, the residual test is
calibrated. None carries residual word-level information: the word's identity
never helps predict the variant once position, scribe, location and ±1 glyph
context are known. For f and cph the samples are below the calibrated size,
so no verdict is possible.

**Paired arm (full vs collapsed context).** Using full v101 symbols in the
context features never improves prediction by a detectable margin. Differences
are within ±0.005 bits, and every interval for CTRL and CTRL+RES includes 0.
So there is **no variant coherence**: which variant appears does not predict
which variants appear nearby. For d with the WIDE features, full context is
slightly worse (−0.0024 [−0.0045, −0.0004]). That is a sparsity cost, not
coherence.

### Descriptive detail (post hoc, not part of the pre-set rules)

`variant_posthoc_rates.json` holds minority-form rates by position, neighbour,
hand and language. These tables were computed after the verdicts. The unique-gain
labels above understate positional structure, because the word-initial glyph
is visible to both POS (glyph position) and NB (previous glyph = `^`), so the
two families share credit. The alone-gains show it plainly:

* **p (`g`/`j`) and f (`f`/`u`):** the minority forms `j` and `u` make up 12%
  and 20% of word-initial occurrences, against 52% and 51% word-medially. POS
  alone gains 0.15 bits for p. This is a clear **position-in-word allograph**,
  and one of the few structured variants in v101. The same contrast appears in
  both gallows pairs, which supports this reading (post hoc).
* **d (`8`/`7`):** `7` is 8% of d in hand 1, against 21–26% in hands 2, 3 and 5
  (Currier A 10%, B 23%). It is also 29% after `c` (EVA e) and 10% after `o`.
  This looks like a **scribal and contextual form**, but hand is collinear with
  quire and section, so the scribal part is not separately established.
* **sh (seven v101 forms):** rates are flat across position and neighbours
  (e.g. `2` is 72–79% in every position). Models with controls predict worse
  than the marginal. This is consistent with free variation or inconsistent
  transcription of the sh plume.
* **y (`9`/`(`), k (`h`/`W`), r (`y`/`x`/`Y`/`b`):** minority forms are
  0.8–2.6% of the class and nearly unpredictable.

### What Part A does and does not show

* **Shows:** EVA's mergers of v101 distinctions lose no *word-level*
  information detectable by this test. This was calibrated at 85–100% power for
  a split of about 0.06–0.10 bits, on the six sets with n ≥ 1000. If these were
  distinct letters, their choice would be fixed by the word they spell. It is
  not.
* **Does not show** that smaller residual effects are absent. The calibration
  minority rate (about 20%) is much higher than that of y, k and r (1–3%), where
  power for a given per-occurrence effect is lower. Neither does it show which
  of position, scribe or context drives each variant, because the attribution
  gate failed.

Reading:

* **The boundary coupling is not carried by the variants.** The next word's
  initial helps exactly as much, or slightly less, when variant distinctions are
  kept. In the 06 design the pre-set rule calls the variants noise.
* **Caveat to that verdict.** The FULL arm's *base* model (stem only, no
  context) is better than both COLLAPSED and SHAM, by about 0.01–0.02 bits,
  with intervals above 0. This was pre-declared as descriptive. Part of FULL's
  smaller gain is therefore the base absorbing information, not only extra
  noise. Variant spelling within the stem predicts the word's own ending a
  little. That fits Part A's contextual allography, where a variant is
  conditioned on the glyphs that follow (for example d `7` before y). Which
  set drives it was not tested.
* **Larger gain than ZL3b.** Even the v101-EVA bridge arm, which uses the ZL3b
  glyph rules, gains +0.052, about twice ZL3b's +0.028. Its base accuracy is
  lower (68.4% vs 74.0%). v101's readings, word spacing or line segmentation
  differ from ZL3b in ways that matter here. This was not investigated, and it
  should not be read as a stronger effect in the manuscript.

**Replicates** (COLLAPSED rule). Accuracy is lower in the unit arms because
v101 writes iin, in and ir as single units: words are shorter in units, fewer

descriptive, as pre-declared. FULL is +0.7 points over COLLAPSED and sits among
the shams, so there is no sign that variants matter.

### B2. §19 classifier (descriptive throughout)

| Corpus | Types (freq ≥ 20) | Rate p ≥ 0.5, logistic / boosting |
|---|---:|---|
| v101 COLLAPSED | 276 | 0.0069 / 0.0033 |

* **Interpretation rule (COLLAPSED): fails**, exactly as for ZL3b and IT2a. The
  rate is far below the shuffled corpus and the assembly control. These are
  similarity hypotheses, not homophone classes.
* **Stability vs ZL3b** (28,441 common pairs after transliteration): Spearman
  0.91 (logistic) / 0.84 (boosting), top-100 overlap 52 / 51. The ZL3b–IT2a
  figures were 0.94 / 0.91 and 72 / 74. Pair rankings transfer between
  transcriptions, but the top of the list is less stable with v101.
* **Variant-only pairs (FULL):** 31 type pairs differ only in a variant, almost
  all d `7`↔`8` (for example `7am`/`8am`, `1c79`/`1c89`). Their mean
  probability is 0.074 (logistic) and 0.140 (boosting). One-substitution pairs
  of matched length (617) score 0.124 and 0.101. The one-sided Mann–Whitney p is
  0.18 and 0.07, so there is **no support** for the classifier treating
  variants as more interchangeable than real substitutions. This does not argue
  that they are distinct letters. The classifier did not pass its Voynich gates,
  and d-variant pairs share most of their context by construction of Part A's
  result.

## Overall reading

* v101 agrees with ZL3b as closely as IT2a does, once its glyph mapping is
  inferred.
* v101's extra glyph distinctions look like **allography and transcription
  variation, not hidden letters**. None of six testable sets carries residual
  word-level information, with a calibrated test that would have caught a
  0.06-bit split. A few are structured by position in the word (gallows `j`,
  `u`) or by hand and the preceding glyph (d `7`). Most, including the seven sh
  forms, are unexplained. Keeping the variants adds nothing to the boundary
  coupling, the hidden-boundary transfer or the §19 classifier.
* **The project's two robust findings extend to a third transcription:** the
  Currier B next-initial coupling of n/l/r endings (with a larger gain on v101,
  not explained here) and its transfer to hidden word-internal boundaries.
  Their interpretation is unchanged. A message-free generator also produces the
  coupling (MECHANISM_FINDINGS), so replication across transcriptions
  strengthens the evidence for the regularity, not for meaning.

## Deviations

* **Implementation details the protocol did not fix:** predicted
  probabilities are mixed with a uniform floor of 0.001 so that a class absent
  from a training fold cannot give infinite loss. It is applied identically to
  every model. For the NB and WIDE calibration controls, "most common glyph"
  excludes word-edge markers.
* **Post hoc additions, labelled as such:** the post hoc rate tables and the
  collinearity explanation of attribution.
* **Part B, bridge arm:** the first coupling run crashed in the bridge arm. EVA
  rows whose v101 stem is empty (a single-unit word such as `m` = iin) had no
  family or stem fold. Missing keys now get folds from the project rule applied
  to them alone, which leaves the unit arms' assignment unchanged. Unit-arm
  gains printed before the crash were identical after the fix.
* **Part B, operationalisation:** "clearly exceeds" in the §19 rule was taken
  as exceeding the largest control rate. The rule fails by an order of
  magnitude either way.
* **Part B, B3 tokenisation:** as in `boundary.py`, `*` and `?` are stripped
  from tokens rather than breaking adjacency.
* **Folds:** v101 has text lines on f70, which is not in the frozen folio
  manifest. As the protocol specifies, it was given a fold by the project rule
  and kept in every analysis. The original 08 dropped such folios instead.
